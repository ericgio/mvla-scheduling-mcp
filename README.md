# MVLA Scheduling Assistant

A Claude-powered scheduling tool for MVLA team managers.

Helps managers schedule home games by surfacing field availability, cross-referencing coach and personal calendar conflicts, and suggesting optimal game slots — all through a conversational interface.

**→ [mvla.ericgio.com](https://mvla.ericgio.com)**

## Feedback and contributions

This is a v0 built for a specific use case. If you're an MVLA manager using this and run into issues or have suggestions, please open a [GitHub issue](https://github.com/ericgio/mvla-scheduling/issues/new).
